# Full Stack Web Development Bootcamp

## Description

Completed a comprehensive Full Stack Web Development course covering the fundamentals of modern web development. I gained hands-on experience building responsive front-end interfaces, developing back-end applications and APIs, working with databases, implementing authentication, and deploying web applications.

### Key Skills Learned

* **Front-End:** HTML5, CSS3, Flexbox, Grid, Bootstrap 5, JavaScript ES6, DOM Manipulation, jQuery, React.js & React Hooks
* **Back-End:** Node.js, NPM, Express.js, EJS, REST APIs
* **Databases:** SQL & PostgreSQL
* **Development Tools:** Bash, Git, GitHub & Version Control
* **Other:** Authentication, Web Design & Deployment with GitHub Pages

Overall, the course strengthened my understanding of how the different layers of a web application work together, from designing user interfaces to building server-side logic, managing data, and deploying applications.
